# 管理凭据流读取与激活码数量窗口（2026-10-13）

已授权范围：移除凭据导出容器512KiB、HTTP 600KiB和JWT16KiB人工大小拒绝；激活码创建数量100作为内部请求窗口，不限制一次用户操作总数。默认365天、现有3650天最大有效期、邮箱身份与JWT过期/结构、角色和可信Origin策略不在此改动中变更。
