# ComfyUI 服务端弹性调度与安全回收

## 边界

本实现仅修改 Hailuo 服务端，不要求更新 AIStudio，不增加客户端心跳接口，不改变图片、音频直传及视频直下协议。固定三台的配置上限已移除，配置最多登记100台，但实际并发受 scheduler.maxConcurrentInstances 约束。配置省略 scheduler 时，加载器补齐新调度默认值；直接构造服务的旧测试/嵌入调用仍保留原平台策略兼容性。

源码、测试、生产部署、平台实际计费是四层不同证据。合并源码不会自动补出真实镜像、SKU报价、存储费或重建验收，也不表示已经开启生产扩容/释放。

## 调度

- 每台实例有独立执行锁；慢请求不会阻止其他实例在下一轮继续推进。同机不重复提交。开机候选的决策串行化，保留5090优先及缺卡后尝试其他区域的顺序。
- 未提交的直传任务先获得限时上传预约，默认10分钟。到期可重排，默认延迟1分钟、最多3次预约；整体排队期限不因重排无限延长。
- 上传重排保留原实例亲和及同一作业目录。旧协议的回执不包含来源实例/预约代数，因此绝不把曾分配的直传任务迁到另一台，再把迟到回执误认为新机器的文件。尚未重新预约时拒绝迟到回执；同机再次预约仍使用原任务目录。
- 已有完整上传回执、已提交或提交结果不确定的任务不走上传重排。任务、prompt ID、冻结工作流及随机种子保持不变。
- 超时判断在原生查询之前执行，不再被404、网络错误或实例退避跳过。未知远端执行仍保留原槽位；标记 COMFY_REMOTE_UNCONFIRMED 后只恢复原任务，不重新生成。
- 提交/执行恢复先检查平台电源状态；任务仍在执行期限内时，停机后唤醒原实例再查询。任务已超时失败或取消后，保留未知远端任务的槽位和素材，但不再自动开机，实例显示 `COMFY_RECOVERY_PAUSED`。仍按退避间隔只读检查平台状态；管理员在平台启动原实例后，继续查询原 prompt 并收取迟到结果，不重新生成。不能因为本地终态直接释放仍有未知远端任务的机器。
- 已启用自动开机和弹性创建、且存在对应工作流模板时，实例全部释放后仍接受新直传任务，由模板重新扩容；没有可用实例或启用模板时仍拒绝直传。

### scheduler 默认值

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| uploadReservationTimeoutMs | 600000 | 单次上传预约时限 |
| uploadRetryDelayMs | 60000 | 上传重排后最早再分配时间 |
| maxUploadReservations | 3 | 同一任务最大上传预约次数 |
| idleStopAfterMs | 300000 | 业务无任务后的保温时间 |
| minWarmInstances | 0 | 最少保温实例数 |
| maxConcurrentInstances | 6 | 最大执行槽位/自动开机目标上限 |
| estimatedJobMs | 600000 | 扩容容量规划使用的任务耗时估计，并非成片耗时承诺 |
| targetQueueWaitMs | 600000 | 期望消化排队工作量的时间窗口 |

## 业务闲置关机

保留平台 GPU 低利用率持续30分钟关机策略（setTimerStop 的 stopType="2"、utilizationRate=10、leisureTime=30），不调用取消接口。平台30分钟策略与服务端5分钟业务空闲关机并存，业务空闲按任务及结果状态判断，并非GPU利用率。首次确认就绪时按持久标记设置一次，观察到停机后重置，重新开机再设置；不将取消平台关机作为派发或恢复原任务的前置条件，已提交任务的查询不依赖设置关机策略。

只有无任务槽、无绑定未完成任务、无未收取结果，并且原生健康及队列均确认空闲，才发出关闭请求。关机意图先持久化，关闭请求不确定时继续查状态，不盲目重发。平台外部人工关机不受服务端保护；恢复仍查询原任务。

## 弹性创建

elastic 默认不配置/不启用。启用必须提供：

1. maxInstances 和创建冷却；实例总数及并发上限均最多100。maxHourlyCost 可选；不配置时只按实例数量限制容量。
2. 配置 maxHourlyCost 时，每个现有实例必须提供 lifecycle.hourlyCost、storageHourlyCost。费率未知时返回 COMFY_COST_UNKNOWN，禁止自动租新机器，不把未知费率当零。
3. 至少一个已验证模板：id、areaName、gpuModel、imageId、imageType、skuName、skuPriceToHourlyFactor、skuPriceUnitVerified、workflowIds、hourlyCost、storageHourlyCost、rebuildVerified、allowRelease。
4. imageId 是保留精度的十进制 int64 字符串；imageType 仅官方的 "2"/"3"；创建使用 skuName，而不是臆造 skuId。单次只创建一台单GPU实例。

按可分配、未绑定的排队工作量以及估计任务耗时计算目标容量；已绑定上传等待、结果收取不单独触发新增实例。容量足够、处于冷却、存在未对账资源，或配置了金额预算且预算不足时不创建。官方没有明确SKU price字段的单位映射，必须由运营方核实并显式设置 skuPriceUnitVerified=true 和 skuPriceToHourlyFactor，不能默认字段就是每小时单价。每次创建前读取对应区域的官方SKU列表，使用已核实的换算系数核对型号和价格不超过模板上限。配置金额预算时，保守预留全部登记实例的计算及存储费率，包括停机实例可能重新开机的计算费用；未配置时不执行金额预算检查。

新增容量不超过实际可分配的任务数；SKU查询返回后再次核对队列和现有容量，避免等待报价期间任务已被其他实例处理，仍按旧需求租机。新资源注册后若平台已在启动或运行，继续探活至可分配，即使原队列已经消失也不遗漏启动检查；无任务时随后按业务闲置策略回收。

模板费率是运营方核实的上限，不是本文提供的报价。镜像、存储和其他收费项必须计入对应预算；未提供真实账单接入，不能把这里的估算当实际结算。

### 创建幂等边界

官方 start 契约没有公开的客户端幂等键或自定义实例名。本实现绝不伪造幂等：

- 请求前写入 comfy_resources 创建意图和预算预留。
- 收到有效实例ID后先持久化，再读取详情，核对地域、镜像、GPU数量及可信原生端点，随后登记为可调度实例。
- 网络中断、超时、无法解析成功回执，或进程退出遗留无ID创建意图：进入 uncertain，阻止后续自动创建。不能靠“新出现且同镜像”的相似实例自动接管，也不能直接重试。
- 已知ID但启动/端点尚未就绪时仅查询该ID；超过对账期限进入 blocked，保持预算预留，继续跟踪该明确ID和持久平台状态，不停止观察。服务端只接受已确认的HTTP 8188原生服务，不拼接其内部端口，不把SSH或其他服务当作ComfyUI。
- 确定拒绝不会被当成已经创建；仍保留记录和冷却。

管理员必须对 uncertain/blocked 在平台核对实际结果后处理，不得直接删除数据库意图来解除闸门。自动恢复不能覆盖官方缺少幂等保证的事实。

## 磁盘释放

可选的已生成未收取结果兜底见 `comfyui-result-archive.md`：10分钟未收取时由GPU直传公开可读的TOS对象，核验并持久保存后才解除该结果的回收保护。默认关闭，不能把未知远端任务当成可归档结果。

close 与 release 分别处理。配置 elastic.releaseAfterMs（默认停机后1小时）只提供回收时间；每台实例还必须显式 allowRelease=true 且 rebuildVerified=true。授权与镜像重建验收完成后，原有实例和弹性新增实例使用同一套关机、释放规则，不按创建来源保留磁盘。缺省值为 false 是未授权保护，不是原有实例永久豁免。

可选 `elastic.stoppedRetention` 启用分层停机保留；省略则沿用所有实例相同的 `releaseAfterMs`，不自动改变旧配置。建议按以下配置仅留1台停机实例30分钟，其余确认停机后1分钟释放：

```json
{
  "releaseAfterMs": 1800000,
  "stoppedRetention": { "maxInstances": 1, "excessReleaseAfterMs": 60000 }
}
```

这些字段放在现有 `elastic` 内。`maxInstances` 是整个池的停机保留数量（0表示全部走快速释放），不是运行中的 `minWarmInstances`；停机保留不保证GPU库存。优先保留最近停机的可安全释放实例，同一停机时间按ID确定顺序；每轮统一选择，避免并发释放时保留名额漂移。保留期从原 `stopped_at` 计算，不因重启或重新入选续期，30分钟到期仍释放。超额释放时间必须为正且不超过长保留期；已停机实例不再额外等待运行空闲的5分钟阈值。所有释放授权、未完成任务和远端未知任务保护仍然生效，被保护资源不计入这1台可回收保留名额。

创建前期无GPU计费不等于完整冷启动免费：2026-10-21的7台账单样本匹配平台Running后按分钟向上取整的GPU费用；到ComfyUI可分配仍有约39–60秒的计费准备时间。停机后的存储费独立，因此缩短停机保留主要节省存储、降低资源占用，不节省已经停止的GPU费用；频繁重建仍有启动延迟和计费准备成本。

rebuildVerified 表示运营方已经验证该镜像能够重建相同模型/节点/工作流，而不是服务端自动验证的声明，也不代表某个 GPU 型号已经完成性能验收。批准统一管理时，应同时更新原有实例的 lifecycle、弹性模板和已登记资源快照；原有实例可登记到同一资源账本，保留原实例 ID，不创建替代任务。自动释放前还必须通过：

- 平台确认已停机；
- 无执行槽、未完成任务、上传重排亲和任务或待收取结果；
- 实例属于本池配置或本池成功创建并登记的资源；
- 没有既存释放请求。

释放意图和 draining 状态在请求前落库。即使释放接口返回成功也保留 releasing，只有详情或明确查询已释放的列表返回同一个ID且 operationStatus="4"，才移除调度配置并记为已释放；不删除历史作业。计费列表未出现该ID、列表扫描完整或接口成功回执，都不能单独证明已释放。释放响应不确定时不重复释放；确定拒绝则恢复可管理状态并延后再试。持久记录防止重启后把已经释放的旧静态配置再次拉起。

释放会删除实例数据。未收取结果始终阻止释放，不以“省磁盘费”为理由丢弃产物。未通过镜像验证或未授权的实例不释放，不区分原有还是新增；也不会扫描并释放账号下未纳入本池的其他机器。已确认释放的原有 ID 重启后不再登记回池；池内实例全部释放后，有新任务仍可使用已验证模板重新扩容。

## 管理和观测

GET /api/admin/comfyui 保留管理员鉴权，增加：

- scheduler：当前服务端策略；
- elastic：启用状态、数量/费用上限及最近安全错误码；
- resources：创建/登记/释放状态，不返回原生地址、令牌、镜像配置正文或工作流；
- metrics：各阶段数量、可分配队列、最老排队时间、近24小时准备/执行耗时中位数和P95，以及成本估算的未知费率计数；
- 实例 idleSince、stoppedAt，便于区分业务闲置、实际停机及存储保留。

POST /api/admin/comfyui/resources/:key/inspect 需要 authorize 权限和审计，只查询本池已确认ID，不会创建或接管相似实例。持久观察可在 resources.platformStatus、observedAt 查看。

对已知ID、从未登记且没有本池任务的创建异常资源，管理员可在确认没有外部工作后调用 POST /api/admin/comfyui/resources/:key/stop-unregistered，正文必须明确 confirmNoExternalWork=true。此接口需要 authorize 权限和审计；只停止本池已确认创建的该ID，不删除磁盘，不接管无ID的 uncertain，也不允许停止已经投入调度的实例。意图在关机请求前持久化，不确定结果不重发；后续继续观察但不自动重新登记/开机。自动维护与管理员操作互斥。

cost.isEstimate 始终为 true，includesHistoricalBilling 为 false；未知费率有显式计数，不把估计费率当真实账单。运行/停机划分依赖服务端已经确认的状态，异常或未知实例按保守费用处理。

## 部署验收

先完成 TypeScript 类型检查、全量 ComfyUI 回归和服务构建，再以真实SKU/镜像及费率配置数量上限和可选金额预算。生产配置与令牌仅留服务器，不提交Git。必须先做镜像重建验收，才能批准对应实例的 allowRelease；不能用虚构价格或未经验证的镜像启用付费扩容及破坏性释放。

本地模拟测试覆盖故障查询超时、同机串行/跨机独立、上传预约重排、创建不确定与重启、预算/数量/报价上限、空闲关机、外部占用、未收取结果保护、停机释放及释放不确定不重试。测试不会创建真实收费实例或删除生产磁盘。
