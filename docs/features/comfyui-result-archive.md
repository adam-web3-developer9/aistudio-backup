# ComfyUI 未收取结果的 TOS 兜底

## 状态与边界

本功能是可选源码能力，默认关闭。需要同时部署服务端、GPU export 扩展及兼容 TOS 地址的 AIStudio 客户端，复用客户端现有火山公有桶、配置独立归档前缀与服务器凭据，再做真实上传验收。不使用私有桶，不修改整个桶或其他前缀的访问策略。仅通过本地测试不代表线上已开启；不会为验收自动创建或开启收费 GPU。

正常路径仍是 GPU 生成、客户端直接下载、本地落盘后发送 `collected`。视频不经 Hailuo 中转。使用独立输出前缀的任务生成完成即可放出执行槽，未收取结果只阻止不安全的关机/释放。

## 兜底流程

1. 仅针对成功且有可下载结果的 direct 任务，从首次成功时间等待600秒；轮询、重启、重签地址不重置期限。已收取、不确定提交、生成失败和非直传任务不进入转存。
2. 到期仍无客户端回执时，调用 GPU 专用扩展，核对原 job/prompt、成功历史和 MP4 输出，取得文件长度、SHA256、MD5。扩展只读取 output 目录中的已验证普通文件，拒绝符号链接和路径穿越。
3. Hailuo 用服务器上的 TOS AK/SK 为唯一对象 key 签发900秒 PUT URL，并用独立 export HMAC 密钥签署精确控制请求。GPU 强制校验 `x-tos-acl: public-read`，重新核对文件后直接流式 PUT 到 TOS。长期 TOS SK 不进入 GPU，Hailuo 不读取视频字节。PUT 预签名 URL 会包含协议所需 AK 标识，不是匿名授权，不能写日志。PUT 使用 TOS4 签名绑定 `host`、ACL、MD5、类型及 SHA256 元数据头；HEAD、DELETE 继续使用官方 SDK。SDK 2.9.1 的公开预签名接口不能签这些上传头，实际请求会被 TOS 以403拒绝，因此不能直接使用该接口生成本功能的 PUT URL。
4. 上传响应不是安全回收凭据。服务端再通过 TOS HEAD 校验对象长度、MD5/ETag及 SHA256 元数据；其中 TOS Content-MD5 校验内容，SHA256 元数据本身不是对象存储自动验算的声明。
5. 校验后在同一 SQLite 事务中持久保存对象 key、上传时间、过期时间，清除 `result_pending`，仅释放该任务自己的槽位。归档不伪造客户端回执，客户端实际回执另记 `collected_at`。
6. 如果没有其他任务或其他待保护结果，实例立即具备关机资格，不额外保温5分钟；仍须通过平台、原生队列、最少运行保温数量等原有关机检查。停机之后沿用分层释放策略。

现有成功结果第一次纳入时使用原 `finished_at`，因此启用配置可能立刻处理已经等待超过10分钟的结果。原生历史已因进程重启而丢失时，扩展不能证明输出归属，会失败保护，不猜测文件或重新生成。

## 重试、竞争与过期

- 独立 `comfy_result_archives` 表记录计划、输出描述、固定 key、摘要、次数和时间；不持久保存短期签名 URL。上传完成但响应丢失时，重试先 HEAD 核对同一 key，不能重新生成视频。
- 同时最多2个归档操作，同一实例最多1个；每个结果最多3次传输尝试，间隔60秒，另有最后一次只读核对机会。失败保留原结果与 GPU 回收保护，通过安全错误码和任务事件暴露原因。当前版本没有自动无限重试或重新开机来归档。
- 客户端回执在上传中到达时记录真实收取事实，但传输结束前仍阻止删机。归档结束不能释放其他新任务的槽位；其他原生任务存在时也不关机。
- 业务有效期为 TOS 原对象上传时间起24小时，不因服务重启或再次查询延长。有效期内返回标准 `https://<bucket>.tos-<region>.volces.com/<object-key>` 公网对象 URL，key 按路径段进行 URI 编码，URL 不含凭据、签名或查询参数，不签 GET。`downloadUrl(key, expiresSeconds)` 暂保留正安全整数形参校验以兼容接口，但该参数不会给公开 URL 设置有效期。
- 过期后外部查询返回 `status=failed`、`stage=result_expired`、`COMFY_RESULT_EXPIRED`，不再提供视频 URL；数据库中的原生成成功事实不改写。客户端保留原任务 ID，不自动重生成；已下载到本地的结果仍可补发 `collected`。
- 服务端到期主动删除本功能登记的对象；删除失败每分钟重试，查询过期不受删除是否成功影响。24小时是业务过期加删除，不是 GET 签名失效；持有公开 URL 的人，在对象删除成功前仍可访问，不能承诺24小时准点停止公网访问。只有经单独批准才可给本功能专用 key 前缀配置生命周期兜底，不更改整个桶或其他前缀策略；平台按天清理不承诺精确24小时删除。原生视频不由扩展删除，实例最终释放后才随磁盘删除。
- 收取和上传同时完成时，已确认的客户端收取不被转存覆盖；已写入的冗余对象仍安排清理。上传失败但可能已经产生的对象，在最终失败后24小时安排清理，原GPU结果仍受保护。对象绑定原桶身份，配置切换到其他桶时不重解释旧key、不签错链接、不跨桶删除。
- 服务端/扩展最长传输时限与文件上限见扩展 README。网络、文件、校验等失败绝不能以“上传请求发过了”为理由解除结果保护。

## 配置与上线

在现有池 JSON 中显式添加：

```json
{
  "resultArchive": {
    "bucket": "your-existing-public-bucket",
    "region": "cn-beijing",
    "endpoint": "https://tos-cn-beijing.volces.com",
    "keyPrefix": "comfy-results",
    "publicReadApproved": true,
    "gpuExporterVerified": true
  }
}
```

桶名示例必须替换成客户端正在使用的真实火山公有桶名。`publicReadApproved: true` 表示运营方明确批准归档结果可被匿名公开读取，`gpuExporterVerified: true` 表示已完成扩展验收；不是程序自动替用户证明，不得未经确认就填写 true。使用独立归档前缀，只给本次上传的对象设置 `public-read` ACL；不改变桶级权限，也不改变客户端参考素材或任何其他前缀的策略。公开 URL 不是秘密授权，知道 URL 即可读取，不适用于必须私密的结果。

服务器专用环境变量：`COMFY_TOS_ACCESS_KEY_ID`、`COMFY_TOS_ACCESS_KEY_SECRET`、`COMFY_RESULT_EXPORT_SECRET`。export 密钥至少32字节，GPU 环境变量 `HAILUO_RESULT_EXPORT_SECRET` 与之对应；密钥不能写入公开镜像、仓库或普通池 JSON。TOS 身份仅授予指定前缀必要的对象 PUT、HEAD（对应对象读取权限）、DELETE 及上传时设置 `public-read` 对象 ACL 所需权限，不授予桶管理权限；客户端下载直接匿名 GET，不下发长期凭据。

GPU 扩展位于 `server/comfyui-result-export`。每个已有实例、每个自动创建模板都必须使用已安装扩展并注入独立 export 密钥的启动环境；原有官方镜像并不自动具备这些端点。更新模板需要重新验收工作流与镜像的 `rebuildVerified`，不能仅改一个配置开关。

上线顺序：备份配置和数据库 → 更新兼容客户端 → 安装并验证 GPU 扩展 → 部署兼容服务端但保持关闭 → 配置桶/权限及环境变量 → 使用已授权的测试结果做小文件实际传输、HEAD及回收验收 → 启用池配置。回滚前应保留能查询已归档结果的存储配置，避免切回原生 URL；缺归档能力时查询显式失败，不返回已删除 GPU 的地址。

## 验证

离线测试覆盖十分钟/24小时边界、收取竞争、重启恢复、上传成功丢回执、摘要不符、重试耗尽、后续任务槽保护、实例移除后查询、过期清理失败和配置缺失。HTTP exporter 与 Python 扩展测试覆盖 HMAC、权限、路径、文件类型、响应大小、DNS/SSRF、真实 SDK 离线签名兼容和不泄露秘密。

公有访问离线测试覆盖 `public-read` 强制头、拒绝私有/公开写 ACL、真实 SDK PUT 签名兼容、无签名 GET URL、中文/空格/加号/百分号/查询及片段字符的路径编码，以及保留的 TTL 参数校验。这些测试不证明真实桶策略、匿名 GET 可达性、删除后的访问状态、镜像安装、跨区域流量价格或真实 GPU/TOS 上传已通过；上线验收须另外确认匿名可读及指定对象删除，不修改桶或其他前缀策略。

## 2026-10-22 SSH 独立上传实测

用户授权后通过正常网关提交唯一测试任务 `job_gateway_comfy_1780b578-b955-4446-8f11-f92558ba6cfc`，使用现有 H3 工作流、512×512、请求1秒，无参考素材。实际生成1.625秒 H.264/AAC MP4，159191字节。提交至完成157.389秒，原生提交至完成约57秒，包含冷启动及测试端输入确认等待。

在任务成功后，通过平台实例详情提供的 SSH 通道，把现有 exporter 源码及小型包装器送入独立 Python 进程内存，读取 localhost 原 prompt history 并核对任务标记、输出及文件摘要，再由 GPU 直传 TOS。没有安装 custom_nodes，也没有重启 ComfyUI；上传前后 ComfyUI PID 均为889。

首次真实 PUT 暴露 host-only 预签名缺少上传头签名，返回403 AccessDenied。改用 Python 官方 SDK 完整签头验证成功后，修正服务端 Node PUT 签名，再用 Node 新签名从同一 GPU 向另一个独立测试 key 上传同一视频，同样成功。两个对象均通过 SDK HEAD 大小、MD5、SHA256核对，匿名 GET 返回200且下载SHA256与GPU原文件一致。测试对象随后已删除并以HEAD确认不存在；视频保留在测试电脑。测试实例已确认平台状态22（关机）。

此实测证明 SSH 独立进程、GPU直传、Node签名及公开下载可用。十分钟自动触发、SSH执行器接入归档调度、任务结果URL自动回写和24小时实际保留仍未完成端到端验收；线上归档开关保持关闭，不能将手动测试当作自动归档已上线。
